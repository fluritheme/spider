# Changelog

## 0.1.3 — 2026-11-08

- Vary physical webs between irregular draped sheets, off-center fans and sparse, branched bridges. Each construction gets its own spacing, tension, open pockets and finer lacing.
- Give support, capture and tying silk different weights and stable variations in reflectance.
- Follow already-laid curves when walking between stitches, with shared live knots that stay connected during reflow.
- Keep finished webs instead of deleting old construction groups. At the 2,048-strand ceiling, stop adding silk until explicitly cleared.
- Preserve exploration draglines and interrupted strands, and retain support identities across temporary hiding.
- Stop scroll gestures from causing walking drift or pointer-triggered fleeing.
- Keep all automatic silk white, including the descent thread, with a faint outline for light backgrounds and independent body coloring.
- Refresh actual runtime README previews and add regression coverage for physical connectivity, retained silk and scrolling.

## 0.1.2 — 2026-11-08

- Apply burnt-pumpkin, charcoal, ivory, and amber styling across the website and preview assets.
- Redesign the README with a branded header, live weaving capture, and focused desktop, phone, and character previews.
- Add an original 1280 × 640 GitHub social card and a reproducible renderer.
- Make the shelter regression test use controlled animation time, avoiding hosted-WebKit frame throttling.

## 0.1.1 — 2026-11-08

- Rebuild the website as a Halloween live habitat with oversized typography, dark controls, and improved runtime previews.
- Sample actual font ink contours and affine object edges for silk attachments.
- Weave layered hanging sheets with catenary-profile strands and staggered cross-ties.

- Remove pointer-driven web erasing. Clicking, Shift-clicking, and dragging preserve woven silk and ordinary page interactions.
- Keep explicit removal through clearWebs() and the playground’s Clear webs button.

## 0.1.0 — 2026-11-08

- Original procedural jumping spider with articulated striped legs, fuzzy outlines, glossy blinking eyes, and stable coloring.
- Whole-viewport exploration, pointer/touch fear, rest/weave behavior, object hiding, and emergence.
- Document-anchored physical weaving: letter/object supports, curved cross-threads, persistent draglines, and a silk descent entrance.
- Shift + primary-button sweep erases whole woven sections; clearWebs() and live update() preserve lifecycle control.
- Foreground occlusion, rounded clipping, overflow handling, and transformed shelter silhouettes.
- SSR-safe ESM/TypeScript API, complete cleanup, reduced-motion support, and bounded high-DPI rendering.
- Responsive interactive playground and Cloudflare Workers deployment for spider.fluri.xyz.
