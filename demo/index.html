A FEW THINGS TO KNOW

The fine threads.

Will it get in the way?

The decorative canvas ignores pointer events and stays out of the accessibility tree. Your links, text selection, and scrolling keep working. Use data-spider-ignore to keep any area spider-free.

What about phones and reduced motion?

The spider works in page coordinates on every screen. Tap near the spider to startle it. It explores the document and takes shelter behind cards and other objects. With reduced motion enabled, it becomes a still illustration; blinking, weaving, swaying, and pointer reactions stop.

How does it understand layers?

It measures marked elements, intersects overflow containers, clips rounded corners, and samples browser hit-testing for foreground occlusion. It works best with rectangular cards. Visibility masks use a 12px grid; rotated shapes, pointer-transparent overlays, shadow DOM interiors, and iframe content have limits. See the README for details.

Can I make it my own?

Choose color, scale, speed, web span, opacity, fear radius, and resident count. Use the controller to pause, resume, refresh, or remove everything. Source and full API documentation are on GitHub.
